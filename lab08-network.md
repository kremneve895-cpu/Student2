# Лабораторная работа. Задание 8. Своя сеть: Redis

Выполнила: студентка, Docker Lab 1, task08-network

## Цель
Создать пользовательскую сеть Docker и запустить в ней Redis,
убедиться, что контейнер доступен по имени внутри сети.

## Шаги

1. Создана пользовательская сеть:
   docker network create my-network
   (сеть уже существовала с прошлых экспериментов — Docker вернул
   сообщение об этом, что подтверждает корректность сети)

2. Запущен Redis в этой сети (без проброса портов наружу):
   docker run -d --name redis-server --network my-network redis
   Контейнер запущен в фоновом режиме (-d), порт наружу не открыт —
   Redis доступен только контейнерам внутри сети.

3. Проверка ответа Redis:

   $ docker exec -it redis-server redis-cli ping
   PONG

4. Просмотр сети и IP-адреса:

   $ docker network inspect my-network
   ...
       "Name": "redis-server",
       "IPv4Address": "172.19.0.2/16",
   ...

## Результат
- Redis отвечает PONG.
- Контейнер redis-server получил IP 172.19.0.2 в сети my-network.
- Контейнеры в пользовательской сети видят друг друга по имени
  (redis-server), без указания IP — как и заявлено в задании.
